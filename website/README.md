# DEVX LIMITED

Responsive English-only company website. Static files are in `dist/`.

Run `node build.cjs` after editing page content. Run `node server.cjs` to preview at http://127.0.0.1:4173. No package installation is required.

Deploy the contents of `dist/` to a static web host. Includes home, privacy policy, terms, cookie policy and contact pages.

Company name, address and business registration number were transcribed from the supplied business registration certificate. The certificate image is not included. Service descriptions are proposed copy based on the stated mobile development business. The phone interface is a labeled illustrative concept, not an actual client project.

The legal pages describe this informational website, not the data practices of individual mobile apps. Review the proposed retention, provider handling, legal terms and actual business procedures before public release. App privacy policies need the real app data practices, SDKs, permissions, account deletion process and audience. Reference consulted: https://www.pcpd.org.hk/english/about_pcpd/privacy_policy_statement/privacy_policy_statement.html

All contact actions open the visitor's email client. There is no backend contact form, analytics, third-party font request, cookie or browser storage in the website code. Hosting infrastructure can have separate logging and access cookies.
