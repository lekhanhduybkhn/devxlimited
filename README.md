# DEVX LIMITED

Website tiếng Anh thuần HTML/CSS nằm trong thư mục `index/` ở cấp cao nhất của dự án. Không cần giải nén, cài thư viện hoặc chạy build.

Mở `index/index.html` để xem. Chỉnh trực tiếp các file HTML và `index/style.css`.

## Vercel

- Đưa riêng các file bên trong `index/` lên gốc repository GitHub, rồi import repository vào Vercel và Deploy. File `index/vercel.json` đã cấu hình không build và xuất bản thư mục hiện tại (`.`).
- Nếu đưa toàn bộ dự án lên GitHub, giữ Root Directory ở gốc repository. File `vercel.json` ngoài cùng đã cấu hình xuất bản thư mục `index`.

Thư mục `public/`, `website/` và file ZIP là các bản trước. Bản dùng và chỉnh sửa từ bây giờ nằm trong `index/`.

Website gồm trang chủ, Privacy Policy, Terms & Conditions, Cookie Policy và Contact. Liên hệ mở ứng dụng email tới admin@devxlimited.com.
